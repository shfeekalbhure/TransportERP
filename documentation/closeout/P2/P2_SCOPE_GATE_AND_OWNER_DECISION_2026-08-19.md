## 1. الغرض

هذه الوثيقة لا تفوض برمجة P2 ولا تختار مجالًا بالنيابة عن مالك المشروع. غرضها تحويل المجالات المؤجلة صراحةً في نطاق P1 إلى قائمة مرشحين قابلة للاعتماد، مع تحديد البوابات التي يجب إغلاقها قبل إنشاء أي عقد أو PR. لا يُعد أي مجال أدناه داخل P2 حتى يختار المالك مجالًا محددًا ويعتمد حدوده كتابةً.

## 3. بوابة اختيار المجال

## 4. بوابات ما قبل البرمجة

لا ينتقل المجال المختار إلى البرمجة إلا بعد توفير دليل مصدر أو مرجع مؤسسي لكل قرار غير بديهي، وإغلاق سجل بيانات W1، وسجل أفعال W2، وسجل شاشات W3، وسجل اختبارات القبول، ومصفوفة الصلاحيات والعزل، وسياسة Offline/Online والمزامنة، وحدود المحاسبة والتحصيل إن كان المجال يؤثر فيها، ونموذج الترحيل وقواعد الفشل وإعادة المحاولة.

يجب أن يكون لكل حقل تشغيلـي مصدر واضح، ولكل فعل نتيجة نجاح وفشل وصلاحية وسجل تدقيق، ولكل شاشة مخرجات وتحققات وحالات تحميل أو انقطاع اتصال. لا يجوز إنشاء Physical Schema أو Migration قبل اعتماد العقد الفيزيائي للمجال المختار ومراجعة استقلالية تؤكد اكتماله.

## 5. مخرجات P2 الإلزامية قبل أول PR

| المخرج | شرط الإغلاق |
|---|---|
| P2 Release Scope | معتمد من المالك ومحدد الحدود |
| W1 Data Contract Register | كامل الحقول والمصادر والقيود |
| W2 Action Contract Register | أفعال النجاح والفشل والصلاحيات والتدقيق |
| W3 Screen Contract Register | شاشة واحدة لكل عقد، RTL، مدخلات ومخرجات وحالات |
| Acceptance Test Register | حالات happy path وnegative وidempotency وoffline/audit |
| Domain Coverage Register | يربط كل متطلب بعقد واختبار ودليل |
| Security and Isolation Matrix | شركة/فرع/دور/جهاز/توكن |
| Physical Schema Proposal | لا يُعتمد قبل إغلاق العقد |
| Independent Review Assignment | يصدر قبل فتح PR |

## 6. قاعدة عدم التخمين

إذا لم يثبت الحقل أو السلوك أو الشاشة أو التكامل في مصدر موثق، يسجل كـ`OPEN` أو `NEEDS_OWNER_DECISION` ولا يتحول إلى تنفيذ ضمن P2. يمكن استخدام مراجع الشركات والأنظمة المعروفة لاكتشاف البدائل والأنماط، لكن لا تُعتبر أي خاصية متطلبًا للنظام قبل توثيق قرار اعتمادها وربطها بعقد واختبار.
