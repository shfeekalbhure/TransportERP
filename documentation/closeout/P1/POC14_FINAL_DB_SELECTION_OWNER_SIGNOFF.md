# سجل اعتماد المالك — قرار قاعدة بيانات POC-14

**المشروع:** TransportERP  
**القرار:** PostgreSQL 18.6  
**الحالة:** `OWNER_ACCEPTED`  
**تاريخ الاعتماد:** 2026-08-19  
**المالك:** شفيق — Project Owner

## نص الاعتماد

اعتمد مالك المشروع نتيجة POC-14 والتوصية المراجعة مستقلًا، ووافق على اعتماد PostgreSQL 18.6 بوصفه قاعدة البيانات الإنتاجية لنظام TransportERP. يشمل القرار استخدام PostGIS للمتطلبات المكانية عند تثبيت الإصدار المتوافق، ويأذن بالانتقال إلى تصميم Physical Schema وإنشاء EF Core Migrations وتنفيذ P1 الإنتاجي.

## حدود الاعتماد

هذا الاعتماد لا يعني أن Production Schema أو Migrations قد أُنشئت مسبقًا، ولا يعني أن أي Migration مسموح بتشغيلها على الإنتاج مباشرة. يجب أن تمر كل مرحلة بتدقيق العقود، واختبارات البناء والتطبيق والتراجع، ومراجعة مستقلة قبل التشغيل الإنتاجي.

يجب أن تبقى مواصفات السلوك والحقول ودورات الحياة في عقود W1 وW2 وW3 هي المرجع الحاكم. أي إضافة خارج العقود تحتاج إلى طلب تغيير وإصدار جديد. كما يبقى دعم Offline/Online والمزامنة وسجل التدقيق ومتطلبات تعدد الشركات والفروع إلزاميًا في التصميم والتنفيذ.

## أدلة القرار

| الدليل | الحالة |
|---|---|
| بروتوكول POC-14 المعتمد | مكتمل |
| سجل السيناريوهات | 14 سيناريو |
| نتيجة الحمل L1/L2/L3 | 312 عينة، بلا أخطاء خروج |
| المراجعة المستقلة | جميع فحوص الاتساق الآلية PASS |
| PostgreSQL p95 مقابل MySQL | أقل في المستويات الثلاثة |
| سجل القرار المعماري ADR-001 | `ACCEPTED_BY_OWNER` |

**قيد تتبع حالي — 2026-08-25:** تقرير المراجعة المستقلة وبروتوكول POC-14 المشار إليهما تاريخيًا غير موجودين داخل شجرة المستودع الحالية. يبقى قرار المالك نافذًا، لكن لا توصف سلسلة الأدلة بأنها مكتملة أو قابلة لإعادة الفحص من المستودع وحده قبل استعادة النسختين المطابقتين والتحقق من بصماتهما.

## البوابة التالية

تُفتح الآن بوابة `PHYSICAL_SCHEMA_AND_MIGRATIONS`. ويجب تنفيذها على فرع مستقل من `master`، مع إبقاء كل ملفات POC-14 المؤقتة خارج مشاريع الإنتاج وعدم استخدام مخططات الاختبار المؤقتة بوصفها Production Schema.
