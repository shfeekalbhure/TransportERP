# TransportERP — خريطة السجل الموحد والتتبع لإصدار P1

## الحكم التنفيذي

تم توحيد السجلات المتاحة دون حذف الصفوف القديمة أو اختراع معرفات للشاشات غير الموثقة. يحتفظ السجل الموحد بـ **165 جدولًا قديمًا** ويضيف **8 كيانات تغطية صريحة** للمتطلبات التشغيلية الجديدة، ليصبح المجموع **173 صفًا**. كما يحتفظ بـ **321 شاشة قديمة** ويضيف شاشة **حالة المزامنة** التي لا يوجد لها مقابل موثق في السجل القديم، ليصبح المجموع **322 شاشة**.

> التوحيد يثبت الهوية والتغطية المرجعية فقط؛ ولا يساوي إغلاق عقود W1 أو W2 أو W3. الإغلاق يتطلب تعبئة الحقول التقنية والاختبارات والأدلة ومراجعة المالك.

## كيانات التغطية المضافة

أُضيفت الكيانات التالية إلى السجل الموحد لأنها تمثل متطلبات صريحة لا تظهر ككيانات مستقلة في السجل القديم. جميعها، باستثناء `SyncOperations`، موسومة بأنها **تغطية مقترحة** إلى حين اعتماد عقد W1 مستقل أو قرار دمجها داخل كيان قائم.

| الكيان | سبب الإضافة | قرار مطلوب |
|---|---|---|
| `SyncOperations` | طابور المزامنة، إعادة المحاولة، التعارضات، والتدقيق | استراتيجية حل التعارض والاحتفاظ |
| `PaymentMethods` | نمذجة طرق الدفع الست المركبة | الأكواد وقواعد المزج |
| `CollectionPolicies` | جهة التحصيل ونقطة التحصيل والاستحقاق | تثبيت الجهات الخمس وتاريخ الاستحقاق |
| `SettlementDistributionRules` | توزيع كشف الترحيل بين السائق والمكتب والباص والمندوب | أساس النسب قبل/بعد الخصم |
| `RestrictedItems` | قائمة المنع والقيد والتنبيه وصلاحية التجاوز | القائمة والصلاحيات المحلية |
| `PricingEvaluations` | حفظ نمط التسعير والعوامل والاقتراح والاعتماد | أولوية عوامل التسعير |
| `DiscountApprovalCases` | مسار توافق الخصم الثنائي والإشعار | القناة والمدة وحد الاعتماد الثالث |
| `WaybillCustomsData` | تبويب الجمارك الإضافية داخل البوليصة | المسارات والأصناف المحلية |

## فجوة النطاق

تذكر الكراسة الأم نطاقًا قدره **238 جدولًا** و**593 شاشة**، بينما السجلات الصفية المتاحة قبل التوحيد تحتوي **165 جدولًا** و**321 شاشة**. لذلك فإن السجل الموحد لا يدعي إغلاق نطاق 238/593. يجب إما استخراج الصفوف الناقصة من مرجع حاكم قابل للتدقيق، أو اعتماد تقسيم رسمي إلى إصدارات، ثم إنشاء عقود W1/W3 لكل دفعة.

## بوابة الانتقال

الانتقال إلى المرحلة التالية مسموح على أساس P1 فقط. وتظل العناصر التالية بوابات مانعة للتفويض النهائي: اعتماد الكيانات المقترحة أو دمجها، اعتماد القرارات المحلية الثمانية، تعبئة عقود W1/W2/W3، تصميم `SyncOperations`، وتوفير اختبارات قبول وأدلة تنفيذية.
