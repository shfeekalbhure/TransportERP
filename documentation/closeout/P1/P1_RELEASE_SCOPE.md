# TransportERP — P1 Release Scope

**Release_ID:** `P1-PLATFORM-SETTINGS-ACCOUNTING-2026-08`  
**الحالة:** `READY_FOR_OWNER_ACCEPTANCE`
**الغرض:** إغلاق الأساس المشترك الذي تعتمد عليه بقية الوحدات دون فتح نطاق تشغيلي أكبر من الأدلة الحالية.

## 1. داخل النطاق

| المجال | داخل P1 | مخرج الإغلاق |
|---|---|---|
| المنصة الأساسية | الهوية، المستخدمون، الأدوار، الصلاحيات، المؤسسات، الفروع، العزل، الإعدادات العامة | W1/W2/W3 واختبارات الصلاحيات والعزل والتدقيق |
| الإعدادات | الإعدادات العامة وإعدادات المؤسسة والفرع وإعدادات الحسابات | عقد إعدادات، أولوية القيم، التحقق، Audit، Offline Policy |
| الحسابات | دليل الحسابات، الفترات، العملات، الأبعاد المالية، القيود، سندات القبض والصرف، الاعتماد والترحيل والعكس والتقارير الأساسية | W1 مالي، W2 للأفعال، W3 للشاشات، E2E مالي |
| التدقيق | سجل الأحداث والفاعل والوقت والسبب وCorrelation ID | Contract + Security/Audit tests |
| Offline/Online الأساسي | سياسة القراءة/الطابور للصلاحيات والإعدادات والبيانات المسموح بها | Sync contract + conflict/retry evidence |

## 2. خارج النطاق ومؤجل

تؤجل إلى إصدارات مستقلة: البوالص والشحن والمحلات، التوصيل، النقل الخفيف والمتوسط والثقيل، مشوار، السفريات والتذاكر، الأسطول وGPS، الصيانة، الموارد البشرية، الجمارك، وتكاملات المزودين الخارجية، ما لم يعتمد مالك المشروع تغيير نطاق مكتوب.

## 3. التبعيات

لا تدخل P1 أي عملية تشغيلية تعتمد على كيان أو فعل غير مغلق في W1/W2. ويجب أن يثبت الحسابات حدود التكامل مع التوصيل والتحصيل لاحقًا دون اختراع نموذج شحن أو توصيل داخل P1.

## 4. شروط الخروج

يخرج P1 من G1 فقط بعد اعتماد مالك المشروع لـ`Release_ID` ونطاقه واستبعاداتـه وتبعياته. ويخرج من التفويض المرحلي فقط بعد إغلاق W1/W2/W3 داخل النطاق، واجتياز اختبارات الهوية والصلاحيات والإعدادات والتدقيق والحسابات والمزامنة الأساسية والمراجعة المستقلة.

## 5. حالة حزمة العقود قبل اعتماد المالك

أصبحت سجلات `W1_DATA_CONTRACT_REGISTER.csv` و`W2_ACTION_CONTRACT_REGISTER.csv` و`W3_SCREEN_CONTRACT_REGISTER.csv` مكتملة الحقول ومربوطة بعقودها واختباراتها، وحالتها `READY_FOR_OWNER_ACCEPTANCE`. أُضيف عقد `SyncOperation` الجديد من الصفر، مع سياسة المزامنة والتعارض وإعادة المحاولة. لا تعني هذه الحالة أن الكود أو الـMigrations أو الشاشات التنفيذية موجودة، ولا تمنح تفويضًا برمجيًا نهائيًا قبل اعتماد المالك واجتياز بوابات الاختبار والمراجعة المستقلة.
