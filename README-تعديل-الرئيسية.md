## التحقق والأدلة

الأدلة في `delivery-evidence/main-layout`: صور قبل/بعد، سجلات البناء والفحص، خريطة الشجرة، وسجل مصدر التغييرات. معاينة التشغيل تفتح نفس FrmMain من المشروع داخل مضيف معاينة منفصل؛ لا تغيّر نقطة الدخول الفعلية ولا تتفاعل مع تسجيل الدخول.

اجتازت الدفعة الحالية 274 تحققاً، تشمل 75 مساراً، و63 مساراً فارغاً، و11 مساراً ذا محتوى، وموارد الأيقونات، وست دورات طي/فتح، وعدم التكرار بعد إعادة البناء والبحث، وحفظ العقد والتحديد، وترتيب الأعمدة وعدم تداخلها عند 1100×620 و1920×1080 و920×560. الفحص لا يظهر نوافذ ولا يثبت حفظ بيانات تشغيلية. تفاصيل الأدلة وحدودها في `delivery-evidence/main-layout/visual-verification.md`.

الصور الموجودة تخص تعديل التوزيع قبل إضافة الأيقونات والطي، ولا تثبت الدفعة الحالية. بعد إعادة تشغيل البرنامج تعذّر جلب قائمة النوافذ مرتين وأُعيدت تهيئة أداة التحكم؛ لذلك بقيت صور الأيقونات وحالتي الطي والأحجام الثلاثة والتحقق المرئي للمصمم معلّقة. المصدر الحالي بُني بنجاح واختُبر دون نوافذ، ولم يُستبدل بهذه الصور القديمة.

فتح المصمم ليس مثبتاً بمجرد نجاح البناء أو وجود ملف Designer: عند المحاولة ظهرت أخطاء إضافات Codeium/CodeGPT، ثم ظل Visual Studio في استعادة NuGet مع تأخر الاستجابة. صورة الحالة محفوظة؛ لم تُعطل إضافات أو تغيّر إعداداتها ولم تُغلق نوافذ المستخدم. أي قبول نهائي للمصمم يحتاج فتحه بنجاح فعلياً.
