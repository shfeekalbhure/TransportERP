# القرار التنظيمي رقم UI-DOC-001
## تنظيم وثائق وتصاميم شاشات TransportERP حسب المجموعات والشاشات

**الحالة:** معتمد  
**تاريخ الاعتماد:** 2026-08-06  
**النطاق:** جميع أعمال تحليل وتصميم وتوثيق شاشات TransportERP.

## القرار
تعتمد بنية موحدة لوثائق وتصاميم الشاشات داخل `Documentation/UI-Design`، بحيث تكون كل مجموعة وظيفية في مجلد مستقل، وكل شاشة في مجلد مستقل داخل مجموعتها، وتوضع صور كل تبويب بصورة منفردة داخل مجلد الشاشة.

## الهيكل الأعلى

```text
Documentation/
└── UI-Design/
    ├── 00-Standards/
    ├── 01-Geographic/
    ├── 02-General-Setup/
    ├── 03-Security-Administration/
    ├── 04-Accounting/
    └── 05-Budget-Financial-Control/
```

## ملف المجموعة
يتضمن تعريف المجموعة، شاشاتها وتبويباتها، القواعد المشتركة، حالة كل شاشة، ما تم وما تبقى، والروابط إلى ملفات الشاشات والصور.

## ملف الشاشة

```text
<Screen-Code>-<Screen-Name>/
├── README.md
├── تحليل_الشاشة.md
├── مواصفات_الحقول.md
├── اختبارات_القبول.md
├── سجل_النواقص.md
└── Designs/
    ├── Drafts/
    └── Approved/
```

## قواعد إلزامية
- صورة مستقلة لكل تبويب.
- عدم خلط تفاصيل عدة شاشات في ملف واحد.
- القواعد المشتركة توضع في الدليل أو ملف المجموعة.
- الخصائص الخاصة توضع في ملف الشاشة.
- لا تعتبر الشاشة معتمدة أو منفذة إلا بعد تحديث حالتها صراحةً.
- يجب قراءة دليل التصميم الموحد وسجل القرارات قبل بدء أي تصميم.
