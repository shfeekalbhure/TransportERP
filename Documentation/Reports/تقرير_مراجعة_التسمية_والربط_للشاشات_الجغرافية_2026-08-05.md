# تقرير مراجعة التسمية البرمجية وربط الشاشات الجغرافية

**المشروع:** TransportERP  
**الفرع:** `setup/initial-solution-structure`  
**التاريخ:** 2026-08-05  
**النطاق:** GEN-004 المحافظات، GEN-005 المديريات، GEN-007 المناطق، والربط مع `FrmDashboard`.

## 1. نتيجة المراجعة

تمت مراجعة ملفات الشاشات الثلاث وملفات المصمم الخاصة بها. وُجدت أسماء افتراضية أو غير متوافقة مع وظيفة الأداة، من أمثلتها:

- `panel2`, `groupBox1`, `tableLayoutPanel1`.
- `button1` إلى `button12` لعناصر قديمة أو مكررة.
- `comboBox1` في شاشة المحافظات رغم أنه يمثل اختيار الدولة.
- `textBox2` في شاشة المحافظات رغم أنه يمثل قيمة البحث.
- `dgvGovernorates` مستخدم داخل شاشتي المديريات والمناطق.
- `txtDirectorateNameAr` معرف كـ `ComboBox` داخل شاشة المناطق رغم أنه يمثل اختيار المديرية.
- `InitializeComponent()` كان معطلاً في منشئي `FrmDirectorates` و`FrmAreas`.

## 3. الربط مع الشاشة الرئيسية

تم تحديث `FrmDashboard.Governorates.cs` ليشمل ربط الشاشات الثلاث داخل قائمة «البيانات الجغرافية»:

| الشاشة | كود التبويب | اسم عنصر القائمة |
|---|---|---|
| المحافظات | `GEN-004` | `mnuGovernorates` |
| المديريات | `GEN-005` | `mnuDirectorates` |
| المناطق | `GEN-007` | `mnuAreas` |

تم اعتماد دالة موحدة لفتح الشاشة داخل `_workspaceTabs` مع:

- منع فتح تبويب مكرر.
- إعادة التركيز على التبويب المفتوح.
- استضافة الفورم داخل التبويب بدون حدود.
- التخلص من نسخة الفورم غير المستخدمة عند وجود تبويب سابق.

## 4. ملاحظات فنية مهمة

1. تم تصحيح خاصية `Name` التشغيلية للأدوات ذات الأسماء الخاطئة دون إعادة توليد ملفات Designer الكبيرة، حفاظاً على التصميم اليدوي وعدم تعريضه للتلف.
2. ما تزال بعض معرفات الحقول الخاصة داخل ملفات Designer تحمل أسماء قديمة، لكنها تُعطى أسماء تشغيلية صحيحة فور إنشاء الشاشة. ينصح لاحقاً بعمل Refactor مصمم وآمن بعد تثبيت التصاميم.
3. لم يتم تنفيذ Build من موصل GitHub؛ يجب تشغيل البناء محلياً بعد سحب آخر التعديلات.
4. لم تُنفذ قاعدة بيانات أو API أو منطق حفظ؛ التغيير يخص التسمية والتهيئة والربط البصري فقط.

## 5. الحكم النهائي

- **التسمية التشغيلية:** مصححة للعناصر المؤثرة في الشاشات الثلاث.
- **إنشاء الشاشات:** مصحح للمديريات والمناطق بإعادة `InitializeComponent()`.
- **الربط بالرئيسية:** مكتمل للمحافظات والمديريات والمناطق.
- **سلامة البناء:** تحتاج تحققاً محلياً نهائياً عبر `dotnet build`.
- **إعادة تسمية معرفات Designer نفسها:** متبقي كتحسين تقني غير مانع للتشغيل.
