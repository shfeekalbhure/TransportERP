# Generic toolbar icon replacements

Feather icons, copyright (c) 2013–2023 Cole Bemis, MIT license (see LICENSE.txt).
Retrieved 2026-10-06 from https://github.com/feathericons/feather/tree/main/icons

Included originals: trash-2, x, search, skip-back, chevron-left, chevron-right, skip-forward, printer, lock.
Raw URL pattern: https://raw.githubusercontent.com/feathericons/feather/main/icons/{name}.svg

The Designer/*.png assets preserve the earlier System.Drawing adaptations at 16 logical pixels, now referenced by UcCurrencySetup.resx for design-time rendering. Printer/bin rounded corners are simplified; the lock file is retained as a candidate but no lock function is inferred from the unclear reference tool. No external icons determine ONYX names, content, positions, colors, or functions. These are generic approximations, not verified exact ONYX artwork.

Add/Edit/Save/Close continue to use the project's existing onyx-S01/S02/S10/S13 resources. Their original provenance is not re-established by this change.
