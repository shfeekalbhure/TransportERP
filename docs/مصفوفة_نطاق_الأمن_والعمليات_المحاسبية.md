## بطاقة تدقيق قيد التنفيذ — SEC-001

| البند | التوثيق |
|---|---|
| الرمز والاسم | SEC-001 — المستخدمون |
| التبويبات | الحساب، الأدوار، نطاق الوصول، الأمان، التدقيق |
| الحقول | كود المستخدم*، الاسم العربي*، الاسم الإنجليزي، اسم الدخول*، البريد الإلكتروني، الجوال، الحالة* |
| العمليات | جديد، حفظ، تعديل، إيقاف، حذف، طباعة. لا يوجد «إغلاق» في شريط الأدوات. |
| البحث والجدول | بحث/تصفية: اسم المستخدم والحالة يعملان محلياً. الدور والشركة والفرع ظاهرة كمعايير مطلوبة لكنها معطلة حتى خدمة النظام المعتمدة؛ لا تقبل قيماً محلية. أعمدة الجدول: اسم الدخول، الاسم العربي، الأدوار، الحالة، آخر دخول؛ وترقيم تحت الجدول. |
| حالة التدقيق | **ناقص / غير معتمد** — لا توجد نتيجة Build أو إثبات فتح من الرئيسية أو مراجعة مشرف، كما أن خدمة الأدوار ونطاقات الوصول غير موجودة في المصدر المعتمد. |
| الإجراء التالي | إنشاء/اعتماد خدمة API للأدوار ونطاقات الوصول أولاً، ثم ربط التبويبين بها؛ بعدها يراجع المشرف build ويفتح الشاشة من الرئيسية ويقارنها بالكراسة. |
| المسؤول | مساعد 2: إصلاح SEC-001 فقط. المشرف: البناء والفتح والاعتماد. |
| دليل مطلوب قبل «مطابق بالكامل» | نتيجة Build موثقة، فتح الشاشة من الرئيسية، قائمة مطابقة الحقول/التبويبات، اسم المراجع المشرف، ودليل استدعاء API المعتمد للأدوار ونطاقات الوصول. |

## تصحيح ثابت مثبت

- `SEC-017` هو **تفويض الصلاحيات** حصراً؛ لا يستخدم مسمى مراجعات الوصول.
- أزيلت تعريفات الأصناف المحاسبية المكررة، وصحح كتالوج ACC ليطابق رموز الكراسة.
- ما زال النجاح النهائي مشروطاً بتبويبات العمليات الفعلية، خدمات الخادم، ثم Build واختبار قبول.
