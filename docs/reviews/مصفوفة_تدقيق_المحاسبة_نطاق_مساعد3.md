## دليل ACC-021 المطلوب قبل «مطابق بالكامل»

- [ ] نتيجة بناء موثقة.
- [ ] تأكيد فتحها من الشاشة الرئيسية.
- [ ] توثيق مطابقة: لا تبويبات؛ ثمانية فلاتر؛ جدول قراءة فقط؛ بحث الأعمدة المقررة؛ تحديث/طباعة/تصدير.
