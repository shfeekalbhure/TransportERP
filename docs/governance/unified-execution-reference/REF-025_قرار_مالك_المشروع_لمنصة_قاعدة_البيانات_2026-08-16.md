# TRANSPORTERP — REF-025 / OD-DB-001
## قرار مالك المشروع الحاكم لمنصة قاعدة البيانات

**التاريخ:** 2026-08-16  
**السلطة:** مالك المشروع  
**الحالة:** GOVERNING OWNER DECISION — EFFECTIVE IMMEDIATELY

## القرار

يعتمد مالك المشروع الحالة الحاكمة التالية لمنصة قاعدة البيانات في TransportERP:

- `FINAL DATABASE SELECTION = OPEN`
- `MYSQL 8.4 LTS = ACTIVE COMPARATOR / CURRENT PROJECT DIRECTION`
- `POSTGRESQL 18.x = PREFERRED DATA-PLATFORM CANDIDATE`
- `POSTGRESQL = CURRENT APPROVED = NO`
- `MYSQL RETENTION FINAL DECISION = NO`
- `POC-14 = AUTHORIZED / REQUIRED`
- `CURRENT APPROVED DATABASE PLATFORM CHANGE = NO`
- `IMPLEMENTATION AUTHORIZED = NO`
- `PRODUCTION MIGRATION AUTHORIZED = NO`

## الأثر الحاكم

لا يجوز اعتبار التفضيل الحالي لـPostgreSQL اختيارًا نهائيًا، ولا يجوز اعتبار استمرار MySQL اعتمادًا نهائيًا للاحتفاظ به.

لا يصدر `DATABASE PLATFORM FINAL SELECTION DECISION` إلا بعد استكمال التنفيذ المقاس لـPOC-14، والتحقق من أدلة المقارنة، ومراجعة النتائج بصورة مستقلة، ثم عرض النتيجة على سلطة مالك المشروع.

حتى صدور القرار النهائي يمنع تغيير منصة قاعدة البيانات الإنتاجية على أنها قرار نهائي، أو تنفيذ Production Migration، أو تثبيت Physical Data Layer نهائي على قاعدة مرشحة غير مغلقة، أو تعديل W1 الحاكم بسبب ترشيح غير محسوم.

## الاستمرارية

هذا القرار لا يعيد المشروع من البداية، ولا يلغي الأدلة أو الأعمال السابقة الصحيحة، ولا يوقف أعمال الإغلاق الجارية. يستخدم كقيد حاكم في الكراسة التنفيذية الموحدة، وفي المستودع، وفي أعمال فرق التنفيذ والمراجعة المستقلة.

## النتائج النهائية المسموح بها بعد POC-14

1. `POSTGRESQL = SELECTED DATA PLATFORM`
2. `MYSQL = RETAINED DATA PLATFORM`
3. `POC INCONCLUSIVE — MORE EVIDENCE REQUIRED`
