# REF-011 — سجل الأدلة البصرية المرجعية من الويب لمشروع TransportERP

## الحالة

`WEB-SOURCED VISUAL REFERENCE REGISTER — سجل المراجع البصرية المأخوذة من الويب`

## قاعدة الاستخدام الملزمة

المراجع البصرية التي يسمح بالاقتباس منها في تصميم TransportERP هي فقط الصور واللقطات والإطارات التي تم جمعها من:

- مواقع الشركات والمنتجات الرسمية.
- مراكز المساعدة والتوثيق الرسمية.
- ملفات PDF أو أدلة المنتجات الرسمية.
- الفيديوهات والعروض الرسمية أو الموثقة المصدر.
- صفحات المتاجر الرسمية للتطبيقات عند الحاجة.

ويُستبعد من الاقتباس التصميمي:

- أي صورة أنشأها ChatGPT أو مولد صور.
- أي Mockup — نموذج بصري داخلي تم توليده داخل المحادثات.
- أي صورة قديمة داخلية للمشروع لا يثبت أنها مقتبسة من مصدر ويب حقيقي.
- أي صورة معاد بناؤها أو رسمها اعتمادًا على وصف فقط.

هذه المواد المستبعدة لا تُحذف من المكتبة؛ تبقى تاريخية فقط ولا تدخل مكتبة الاقتباس التصميمي.

## المصادر الحاكمة لهذه المكتبة

1. `SCREEN_EVIDENCE_FILE_INDEX_V3.csv` — فهرس ملفات الأدلة البصرية من أنظمة الشركات.
2. `11_سجل_الأدلة_البصرية_العالمية.csv` — سجل الأدلة البصرية العالمية.
3. `12_فهرس_الصور_المرجعية.csv` — فهرس الصور المرجعية.
4. `13_فهرس_الفيديوهات_والتوقيتات.csv` — فهرس الفيديوهات والتوقيتات.
5. `TransportERP_معرض_الشاشات_المرجعية_V3.html` — معرض روابط الصور الأصلية على الويب.
6. `TransportERP_مكتبة_صور_وفيديوهات_الشاشات_المرجعية_V3.docx` — تقرير المكتبة البصرية العالمية.

## الأدلة الموثقة المكتشفة

ثبت وجود فهرس يحتوي على 37 ملف دليل بصري من مصادر ويب/توثيق شركات، يشمل أمثلة من:

- Oracle — أوراكل.
- Microsoft Dynamics 365 — مايكروسوفت دايناميكس 365.
- Rose Rocket — روز روكِت.
- Motive — موتِف.
- Onfleet — أونفليت.
- Fleetio — فليتيو.
- Betterez — بيتريز.
- Samsara — سامسارا.
- SAP — ساب.

كما يوجد معرض ويب موثق يربط إلى صور أصلية من Oracle — أوراكل، SAP — ساب، CargoWise — كارجو وايز، Samsara — سامسارا، Bringg — برينغ، Fleetio — فليتيو، Workday — ووركداي وغيرها.

## تصنيف الصور

كل صورة ويب تصنف إلى واحدة من:

- `CURRENT VERIFIED — حالية ومتحقق منها`.
- `CURRENT/RECENT — حالية أو حديثة`.
- `VERSION UNKNOWN — الإصدار غير متحقق`.
- `LEGACY REFERENCE — مرجع إصدار قديم`.

الصورة القديمة من شركة حقيقية قد تستخدم لفهم نمط وظيفي فقط إذا وُسمت بوضوح، ولا تستخدم لإثبات الشكل الحالي للمنتج.

## ما يُقتبس من الصورة

الاقتباس المقصود ليس نسخ التصميم حرفيًا، بل استخراج الأنماط المفيدة مثل:

- توزيع الشاشة.
- مناطق العمل.
- التبويبات.
- الحقول والمجموعات.
- الجداول والأعمدة.
- البحث والفلاتر.
- الأزرار والإجراءات.
- الحالات والتنبيهات.
- الخرائط والتتبع.
- مسارات العمل في الجوال.
- أنماط إثبات الاستلام والتسليم.
- أنماط الصيانة والمستودعات والنقل والتذاكر والمحاسبة.

أي اقتباس يدخل تصميم TransportERP يجب أن يراجع مقابل قواعد المشروع الحاكمة قبل اعتماده.

## مساحة العمل

المجلد المعتمد للتجميع:

`/المرجع التنفيذي الموحد لمشروع TransportERP/04_الأدلة_البصرية_والصور/02_صور_مرجعية_عالمية`

ويخصص فقط لصور الويب الحقيقية وما يرتبط بها من فهارس ومصادر.

أما الصور الداخلية القديمة أو المولدة فلا تنقل إلى هذا المجلد.

## البيانات الإلزامية لكل أصل بصري

- `Visual ID — معرف الأصل البصري`.
- `Vendor/System — الشركة أو النظام`.
- `Product — المنتج`.
- `Screen ID — معرف شاشة TransportERP المرتبطة` عند توفره.
- `Source URL — رابط المصدر`.
- `Source Type — نوع المصدر`.
- `Version — الإصدار`.
- `Evidence Status — حالة الدليل`.
- `Supported Claims — ما الذي يثبته الدليل`.
- `SHA-256 — البصمة` إذا كانت البايتات محفوظة.
- `Rights Status — حالة الحقوق`.
- `Reviewer Status — حالة المراجعة`.

## الحكم الحالي

`WEB VISUAL LIBRARY = AUTHORIZED FOR DESIGN REFERENCE — مكتبة صور الويب مصرح باستخدامها كمرجع للتصميم`.

لكن:

`VISUAL COVERAGE COMPLETE = NO — التغطية البصرية الكاملة = لا`.

ويستمر البحث عن صور رسمية إضافية للشاشات التي لا تزال بلا دليل بصري موثوق.
