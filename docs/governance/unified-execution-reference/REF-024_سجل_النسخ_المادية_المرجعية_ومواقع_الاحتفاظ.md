# REF-024 — سجل النسخ المادية المرجعية ومواقع الاحتفاظ

**المشروع:** TransportERP  
**الحالة:** `CANONICAL PHYSICAL INSTANCE REGISTER — سجل النسخ المادية المرجعية`  
**الغرض:** حسم النسخة المادية المرجعية لمجموعات التكرار المؤكدة التي تخص خط V1.25 الحالي، دون حذف أو نقل النسخ الأخرى.

## 1. قاعدة الاختيار

سجل V1.25 يحدد المسار التنفيذي للنسخ الحالية داخل:

`/كراسة التنفيذ 8-8/النسخ المعتمدة الحديثة/`

لذلك، عندما تكون هناك نسخ مادية **متطابقة بايتيًا** للإصدار المنطقي نفسه، تعتمد النسخة الموجودة في هذا المسار بوصفها:

`CANONICAL PHYSICAL INSTANCE — النسخة المادية المرجعية`.

هذا الاختيار:
- لا يغير المحتوى أو البصمة.
- لا يمنح سلطة جديدة؛ السلطة تأتي من V1.25.
- لا يصرح بحذف النسخ الأخرى.
- يجعل النسخ الأخرى `CONTROLLED DUPLICATE COPY — نسخة مكررة محكومة` إلى حين التنظيف النهائي.

## 2. تحقق البصمات قبل الاختيار

تمت إعادة مطابقة النسخ الموجودة في المسار الحالي مع البصمات المثبتة سابقًا في REF-015 وREF-018 وREF-021 وREF-023.

النتيجة:

`CANONICAL-PATH HASH MISMATCHES = 0 — اختلافات بصمة النسخة في المسار المرجعي = صفر`.

## 6. سياسة موقع الاحتفاظ

### النسخة المادية المرجعية

`RETENTION LOCATION — موقع الاحتفاظ` للنسخة المرجعية هو **مسارها الحالي داخل**:

`/كراسة التنفيذ 8-8/النسخ المعتمدة الحديثة/`

ولا تنقل في هذه المرحلة.

### النسخ المادية المطابقة الأخرى

حتى اكتمال تنظيف المكتبة:

`RETENTION = KEEP IN PLACE WITH CONTROLLED DUPLICATE CLASSIFICATION — الاحتفاظ = تبقى في مكانها مع تصنيف نسخة مكررة محكومة`.

لا تنقل إلى الأرشيف ولا تحذف الآن؛ لأن بعضها قد يكون جزءًا من حزمة تاريخية أو أثر مراجعة يجب حفظه.

## 7. أثر السجل على السجلات السابقة

إذا استخدم REF-015 أو REF-018 أو REF-021 أو REF-023 معرف نسخة مادية مختلفة ولكن ذات البصمة نفسها، فإن REF-024 **لا يغير نتيجة التحقق**؛ بل يحدد أي نسخة مادية تستخدم من الآن كمؤشر مرجعي.

القاعدة من الآن:

`AUTHORITY = V1.25 STATUS — السلطة = حالة V1.25`

`CANONICAL PHYSICAL LOCATION = V1.25 CURRENT PATH — الموقع المادي المرجعي = المسار الحالي الذي حدده V1.25`

## 8. الحالة

`CANONICAL PHYSICAL INSTANCE SELECTION FOR VERIFIED DUPLICATE GROUPS = COMPLETE — اختيار النسخ المادية المرجعية لمجموعات التكرار المتحققة = مكتمل`.

`DELETION AUTHORIZED = NO — الحذف غير مصرح`.

`MOVE AUTHORIZED = NO — النقل غير مصرح`.

`OWNER DECISION REQUIRED — يتطلب قرار مالك المشروع = 0` لهذه الدفعة.

الخطوة التالية بعد هذا السجل هي المصالحة الدلالية، مع استمرار استكمال سلسلة الإصدارات للمواد التاريخية/الداعمة الأقدم والمرشحة بالتوازي.
