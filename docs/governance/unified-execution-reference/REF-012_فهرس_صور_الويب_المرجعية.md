## قواعد الاقتباس

1. المصدر الرسمي أو ملف الشركة هو الأساس.
2. الصورة الحالية الموثقة تقدم على الصورة ذات الإصدار غير المتحقق.
3. الصورة القديمة من الشركة تستخدم لنمط وظيفي فقط، ولا تنقل شكلًا حاليًا.
4. لا تُستخدم الصور المولدة داخل ChatGPT — شات جي بي تي أو الصور الداخلية القديمة في هذا الفهرس.
5. كل صورة تُربط لاحقًا بشاشة TransportERP وتبويباتها وحقولها وإجراءاتها قبل اعتماد الاقتباس.
