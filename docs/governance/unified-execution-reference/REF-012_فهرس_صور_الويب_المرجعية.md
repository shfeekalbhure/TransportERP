# REF-012 — فهرس صور الويب المرجعية لمشروع TransportERP

## الغرض

هذا الفهرس يحصر الأدلة البصرية التي مصدرها مواقع الشركات أو ملفاتها أو مراكز مساعدتها أو أدلتها الرسمية، لا الصور المولدة داخل ChatGPT — شات جي بي تي ولا النماذج الداخلية القديمة.

المصدر الأساسي: `SCREEN_EVIDENCE_FILE_INDEX_V3.csv` — فهرس ملفات أدلة الشاشات، مع الاستفادة من `11_سجل_الأدلة_البصرية_العالمية.csv` و`12_فهرس_الصور_المرجعية.csv`.

تم أيضًا نسخ معرض الويب المرجعي إلى مكتبة المشروع داخل:

`/المرجع التنفيذي الموحد لمشروع TransportERP/04_الأدلة_البصرية_والصور/02_صور_مرجعية_عالمية/01_معرض_صور_الويب_المرجعية_TransportERP_V3.html`

وهو يعرض الصور عبر روابطها الأصلية من مواقع الشركات والمصادر الموثقة، ليستخدمه المصمم كمرجع بصري مباشر.

## الأدلة الموثقة

يوجد 37 أصلًا بصريًا موثقًا من مصادر شركات ومراكز مساعدة وملفات رسمية، منها Oracle — أوراكل، Microsoft Dynamics 365 — مايكروسوفت دايناميكس 365، Rose Rocket — روز روكِت، Motive — موتِف، Onfleet — أونفليت، Fleetio — فليتيو، Betterez — بيتريز، Samsara — سامسارا، وSAP — ساب.

التفاصيل الدقيقة، أسماء الملفات، روابط المصدر، حالة الإصدار، البصمات وما يثبته كل دليل محفوظة في `SCREEN_EVIDENCE_FILE_INDEX_V3.csv` — فهرس ملفات أدلة الشاشات.

## قواعد الاقتباس

1. المصدر الرسمي أو ملف الشركة هو الأساس.
2. الصورة الحالية الموثقة تقدم على الصورة ذات الإصدار غير المتحقق.
3. الصورة ذات الإصدار غير المتحقق تستخدم لفهم البنية والتدفق فقط، ولا تثبت الشكل الحالي للمنتج.
4. الصورة القديمة من مصدر شركة حقيقي تستخدم كنمط تاريخي فقط، ولا تنقل كواجهة حالية.
5. الصور المولدة داخل ChatGPT — شات جي بي تي، أو النماذج الداخلية القديمة، لا تدخل هذا الفهرس ولا يعتمد عليها في الاقتباس التصميمي.
6. أي اقتباس بصري يراجع مقابل مواصفة TransportERP الحاكمة قبل إدخاله في التصميم.

## حالة التغطية

`VISUAL COVERAGE = CONTROLLED / PARTIAL — التغطية البصرية = مضبوطة / جزئية`.

لا يعلن اكتمال التغطية البصرية حتى توجد أدلة موثقة كافية للنطاق المطلوب.
