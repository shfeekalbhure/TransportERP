## قاعدة السلطة

الترتيب المستخدم أثناء التوحيد:

1. Owner Decisions — قرارات المالك.
2. Current Approved Governing Sources — المصادر الحاكمة الحالية المعتمدة.
3. Approved/Frozen Contracts — العقود المعتمدة/المجمدة.
4. Independently Verified Frozen Baselines — خطوط الأساس المجمدة المتحقق منها مستقلًا.
5. Representations preserving higher authority — تمثيلات تحافظ على معنى مصدر أعلى.
6. Project-specific drafts — مسودات المشروع الخاصة.
7. Remediation candidates — مرشحات المعالجة.
8. Global benchmark/support — المقارنة/الدعم العالمي.
9. Derived proposal — المقترح المشتق.
10. Assumption — الافتراض.

## القاعدة التنفيذية

`Candidate ≠ Current Approved — المرشح لا يساوي الحالي المعتمد`

`Benchmark ≠ Requirement — المقارنة لا تساوي متطلبًا`

`Implementation Evidence ≠ Governing Authority — دليل التنفيذ لا يساوي سلطة حاكمة`

## الخطوة التالية

فتح هذه الملفات بالترتيب أعلاه، وإضافة كل ملف فعلي إلى Master Artifact Register — سجل الأصول الرئيسي مع:

- File ID — معرف الملف.
- Version — الإصدار.
- SHA-256 — البصمة.
- Authority — السلطة.
- Status — الحالة.
- Supersedes/Superseded By — يستبدل/مستبدل بواسطة.
- Related Contracts — العقود المرتبطة.
- Working Set Inclusion — هل يدخل مجموعة العمل الموحدة؟
