# REF-019 — سجل سلسلة الإصدارات الأولي

**المشروع:** TransportERP  
**الحالة:** `INITIAL VERIFIED LINEAGE — سلسلة أولية متحقق منها`  
**المرجع الحاكم:** `Current Approved References V1.25 — سجل المراجع الحالية المعتمدة V1.25`.

## 1. قاعدة السلسلة

V1.25 ينص صراحة على:

`LATEST APPROVED VERSION WINS — أحدث نسخة معتمدة هي الحاكمة`.

وأي نسخة أقدم لنفس الغرض:

`ARCHIVE / SUPERSEDED — أرشيف / مستبدلة`

ولا تستخدم في التنفيذ.

هذا السجل لا يحذف النسخ القديمة؛ يثبت علاقتها بالنسخة الحالية فقط.

## 3. أدلة التحقق

### الكتاب الموحد

النسخ المرصودة ماديًا في المكتبة تشمل:
- `كراسة_نظام_تصميم_TransportERP_التنفيذية_الموحدة_النهائية_V1.docx`.
- `كراسة_نظام_تصميم_TransportERP_التنفيذية_الموحدة_النهائية_V1.1.docx`.
- `كراسة_نظام_تصميم_TransportERP_التنفيذية_الموحدة_النهائية_V1.2.docx`.
- `كراسة_نظام_تصميم_TransportERP_التنفيذية_الموحدة_النهائية_V1.3.docx`.

V1.25 يسمي V1.3 `CURRENT APPROVED — الحالي المعتمد`.

### API — واجهات البرمجة

V1.25 يسجل:
- إغلاق Paging — ترقيم الصفحات في V1.18 ونقل المصفوفة إلى V1.4.
- إغلاق Lookup — الاستدعاء في V1.19 ونقل المصفوفة إلى V1.5.
- إغلاق HTTP Resilience — مرونة بروتوكول HTTP في V1.20، والحالة الحالية في الجدول V1.6.

النسخ V1.4 وV1.5 موجودة ماديًا في المكتبة، والحالية V1.6 مثبتة في REF-015.

### CoreUI — واجهة المستخدم الأساسية

V1.25 يوثق سلسلة إغلاقات التعارضات:
- V1.22 أدخل قرار `MainDataMaxColumns = 2 — الحد الأقصى لعمودي البيانات الرئيسية = 2` ورفع بعض العقود.
- V1.23 صالح تعارضات العمود الثالث في عناصر تحكم/تخطيط/ملفات.
- V1.24 رفع Shared Controls — عناصر التحكم المشتركة إلى V1.2، وShared Containers — الحاويات المشتركة إلى V1.5، وCoreUI Properties — خصائص واجهة المستخدم الأساسية إلى V1.4.
- V1.25 أغلق النص المتبقي في Transaction Profile — ملف المعاملة V1.1.

## 4. التمييز بين الإصدار والتكرار

`VERSION LINEAGE — سلسلة الإصدار` تختلف عن `PHYSICAL DUPLICATE — التكرار المادي`.

قد توجد نسختان ماديتان متطابقتان لنفس الإصدار؛ هذه ليست إصدارين مختلفين.

REF-018 أثبت مجموعات تكرار مادية متطابقة بايتيًا لعدد من العقود والمصفوفات، ولذلك تسجل كـ:

`SAME LOGICAL VERSION / EXACT BYTE DUPLICATE — نفس الإصدار المنطقي / نسخة مادية مطابقة`.

## 5. ضابط التنظيف

لا يحذف أي ملف أقدم أو مكرر قبل اكتمال ثلاثة أشياء:
1. تحديد `Canonical Physical Instance — النسخة المادية المرجعية`.
2. تثبيت `Retention Location — موقع الاحتفاظ` للأرشيف أو النسخ المطابقة.
3. ربط السجل الحاكم ومسار المصدر والبصمة قبل النقل أو إعادة التسمية.

## 6. الحالة الحالية

`VERSION LINEAGE COVERAGE = PARTIAL / EXPANDING — تغطية سلسلة الإصدارات = جزئية / تتوسع`.

السلاسل أعلاه متحقق منها، لكن بقية عائلات V1.25 ما تزال تحتاج استكمالًا قبل إعلان 100%.

`OWNER DECISION REQUIRED — يتطلب قرار مالك المشروع = 0` لهذه الدفعة؛ قواعد الاستبدال الحالية تكفي للحسم.
