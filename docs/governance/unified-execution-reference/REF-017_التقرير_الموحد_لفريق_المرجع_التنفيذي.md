## 3. الإغلاقات السابقة للمصالحة الدلالية

### 3.1 المصادر الحالية المعتمدة وفق V1.25

تم إغلاق التحقق المادي والبصمات عبر REF-015 وREF-018 وREF-021.

`V1.25 CURRENT-APPROVED LOGICAL SOURCE COVERAGE = 100% — تغطية المصادر المنطقية الحالية المعتمدة وفق V1.25 = 100%`.

الدفعة المكملة في REF-021 شملت:
- جدول التتبع العام V1.
- قرارات الحوكمة والمعمارية G2 V1.2.
- خطة التنفيذ البرمجية الموحدة V1.1.
- تقرير مراجعة خطة التنفيذ V1.1.
- جدول تتبع خطة التنفيذ V1.1.
- تقرير مراجعة العقود التقنية W2 V1.6.

النسخ المادية المتعددة التي أعيد فحصها كانت `EXACT BYTE DUPLICATES — نسخ متطابقة بايتيًا`، ولم يظهر `SAME NAME / DIFFERENT SHA — الاسم نفسه / بصمة مختلفة` في الدفعات الموثقة.

### 3.2 مجموعة الدعم الحالي المحددة في V1.25

تم إنشاء `REF-023 — سجل الدعم الحالي والأدلة المغلقة وفق V1.25`.

تم التحقق ماديًا وبالبصمة من:
- تقرير تغييرات الكراسة الموحدة النهائية V1.
- تقرير إغلاق دقة التخزين الفيزيائية W1.
- تقرير إغلاق المفتاح الفيزيائي UUIDv7 في W1.
- تقرير إغلاق الفجوات V1.6.
- تقرير إغلاق مرونة HTTP في W2.

النسخ المادية المتعددة لثلاثة من هذه الملفات كانت متطابقة بايتيًا.

`IDENTIFIED V1.25 CURRENT SUPPORT SET VERIFICATION = COMPLETE — التحقق من مجموعة الدعم الحالي المحددة في V1.25 = مكتمل`.

ملفات الدعم لا تكتسب سلطة أعلى من المصادر `CURRENT APPROVED — الحالية المعتمدة`؛ وظيفتها حفظ أدلة الإغلاق والتغيير والمراجعة والتتبع.

### 3.3 النسخ المادية المرجعية

تم إنشاء `REF-024 — سجل النسخ المادية المرجعية ومواقع الاحتفاظ`.

القاعدة المعتمدة:

`CANONICAL PHYSICAL LOCATION = V1.25 CURRENT PATH — الموقع المادي المرجعي = المسار الحالي الذي حدده V1.25`.

تمت إعادة مطابقة النسخ الموجودة في:

`/كراسة التنفيذ 8-8/النسخ المعتمدة الحديثة/`

مع البصمات المثبتة في REF-015 وREF-018 وREF-021 وREF-023.

النتيجة:

`CANONICAL-PATH HASH MISMATCHES = 0 — اختلافات بصمة النسخة في المسار المرجعي = صفر`.

`CANONICAL PHYSICAL INSTANCE SELECTION FOR VERIFIED DUPLICATE GROUPS = COMPLETE — اختيار النسخ المادية المرجعية لمجموعات التكرار المتحققة = مكتمل`.

النسخ الأخرى المتطابقة تبقى:

`CONTROLLED DUPLICATE COPY — نسخة مكررة محكومة`

في أماكنها حتى قرار تنظيف لاحق؛ لا حذف ولا نقل الآن.

### 3.4 سلسلة الإصدارات

`REF-019 — سجل سلسلة الإصدارات` أصبح يشمل على الأقل:
