## الوثائق الحالية

1. `REF-001 — وثيقة تأسيس المرجع التنفيذي الموحد`.
   - الهدف، النطاق، مبادئ السلطة، البحث العميق، مراحل العمل.

2. `REF-002 — سجل مسؤولية التنفيذ`.
   - فصل الأدوار، مسؤولية التنفيذ، المراجعة، والاعتماد.

3. `REF-003 — تقرير تهيئة المستودع الأولي`.
   - حالة مستودع GitHub — جيت هب الحالية، المشاريع، والحدود الأولية.

4. `REF-004 — خط الأساس ومجموعة العمل الحالية`.
   - يحدد طبقة `Current Approved — الحالي المعتمد`، نواة V4.1R2، المصادر المحفوظة، المعمارية المشتقة، المقارنة، والأدلة.

5. `REF-005 — خطة الجرد والتنظيف الآمن للمكتبة`.
   - قواعد التصنيف، التكرار، التعارض، الحجر، الأرشفة، ومنع الحذف المبكر.

6. `REF-006 — هذا الفهرس`.

7. `REF-007 — سجل سلطة المصادر الأولي`.
   - سجل أولي من 32 مصدرًا/عائلة مصنفة إلى حاكم حالي، مصدر محفوظ، معمارية مشتقة، مرشح مقارنة، دليل فقط، تاريخي/مستبدل، ومحجور/متعارض.

8. `REF-008 — سجل الفجوات الحاكمة الحالية`.
   - يسجل عوائق الربط الدقيق لـW2، توزيع الحقول والإجراءات، عقود العمل دون اتصال والجوال، إغلاق البيانات وفق W1، الاختبارات والأدلة، والضمان المستقل.

9. `REF-009 — سجل الأصول الرئيسي الأولي`.
   - سجل عائلات الأصول ومواقعها وتصنيفها الحاكم واستخدامها وقرار التنظيف الحالي.

10. `REF-010 — سجل التكرارات والتعارضات الأولي`.
   - يثبت التكرارات والتعارضات ذات الأولوية وقواعد الفحص قبل أي حذف أو نقل.

11. `REF-011 — سجل الأدلة البصرية المرجعية من الويب`.
   - يقصر الاقتباس التصميمي على صور الشركات والمواقع والملفات والفيديوهات الرسمية أو الموثقة المصدر، ويستبعد الصور المولدة داخل ChatGPT — شات جي بي تي والنماذج الداخلية القديمة.

12. `REF-012 — فهرس صور الويب المرجعية`.
   - يسجل 37 أصلًا بصريًا موثقًا من Oracle — أوراكل، Microsoft Dynamics 365 — مايكروسوفت دايناميكس 365، Rose Rocket — روز روكِت، Motive — موتِف، Onfleet — أونفليت، Fleetio — فليتيو، Betterez — بيتريز، Samsara — سامسارا، وSAP — ساب.
