# المجموعة الثالثة — الأمن والإدارة

هذه الحزمة مخصصة للدمج داخل الكراسة الموحدة فقط. تحتوي على كراسة تفصيلية و18 تصميم SVG منفصل.

- لا تتضمن كودًا أو تعديل API أو قاعدة بيانات.
- قرار مقترح للتصعيد: اعتماد شاشتي تفويض الصلاحيات ونطاقات الوصول للبيانات ضمن نطاق المجموعة لبلوغ 18 شاشة.
- يحظر إظهار كلمات المرور والمفاتيح السرية وعوامل الاسترداد أو عناوين الشبكة الكاملة في الواجهة أو التصدير.
