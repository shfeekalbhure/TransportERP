## Global stop conditions

- current ref or selected candidate SHA changes without rebinding evidence;
- any cross-tenant/cross-owner negative succeeds;
- unreviewed DB/migration/data action is required;
- exact rollback/recovery path is unavailable;
- Production credentials or personal data would enter logs;
- canonical accounting, screen, Kurrasa or offline authority is missing for the affected scope;
- preserved work, migration lineage, audit history or API compatibility would be lost.
