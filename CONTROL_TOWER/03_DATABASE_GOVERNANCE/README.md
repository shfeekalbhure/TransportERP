# Database Governance

هذا هو المرجع الحاكم لأي اقتراح أو تغيير يتعلق بقاعدة البيانات.

- `DATABASE_CURRENT_STATE_REGISTER.md` يوثق الواقع المثبت.
- `DATABASE_CHANGE_PROPOSAL_REGISTER.md` يسجل الاقتراحات قبل التنفيذ.
- القرار الحاكم: `../00_GOVERNANCE/DECISIONS/DB-GOV-001.md`.

لا تعدل قاعدة البيانات مباشرة من ذاكرة الفريق أو من تصميم شاشة منفرد.
