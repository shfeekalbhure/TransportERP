# Report Output Rules

1. كل فريق يرفع تقريره وسجلاته داخل مجلده فقط.
2. لا يكتب فريق داخل مجلد فريق آخر.
3. تقرير كل فريق يبقى مستقلًا حتى مرحلة المصالحة المسموح بها.
4. كل مخرج نهائي يسجل في `MISSION_HANDOFF_AND_SEAL_REGISTER.md` قبل التسليم.
5. بعد الختم يمكن إنشاء نسخة أرشيفية للمكتبة دون تغيير الأصل المقفل.
6. أي نسخة معدلة لاحقًا تحمل Version/Hash جديدين ولا تستبدل النسخة السابقة بصمت.
