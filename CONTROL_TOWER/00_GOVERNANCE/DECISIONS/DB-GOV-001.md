# DB-GOV-001 — قرار حوكمة قاعدة البيانات

## القرار
يمنع تنفيذ أي إضافة أو حذف أو تعديل في قاعدة بيانات TransportERP أو Models/Migrations المؤثرة عليها قبل الرجوع إلى `CONTROL_TOWER/03_DATABASE_GOVERNANCE/` وتسجيل التغيير المقترح ومراجعته.

## القواعد
1. الواقع الحالي يوثق أولًا ولا يعاد تفسيره بالتخمين.
2. الحذف يسجل `CANDIDATE FOR REMOVAL` ولا ينفذ تلقائيًا.
3. كل تغيير يوضح المتطلب، الأثر على الشاشات/API/المحاسبة/Sync، وخطة الاختبار/الرجوع.
4. الاختبارات والمهاجرات تجرب على بيئة Disposable غير إنتاجية.
5. لا تستخدم بيانات أو أسرار Production.
6. التنفيذ عالي الخطورة يحتاج قرارًا مستقلًا صريحًا.
