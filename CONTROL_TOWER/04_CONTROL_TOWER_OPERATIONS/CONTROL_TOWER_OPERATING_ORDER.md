# Control Tower Operating Order

## الوظيفة
إدارة التسلسل والرقابة والتوجيه والتسليم بين المهام، دون استبدال الفرق الفنية.

## دورة العمل
CHECK PREREQUISITES → ISSUE/CONFIRM START → MONITOR REQUIRED OUTPUTS → VERIFY SEAL → HANDOFF → UPDATE QUEUE.

## قواعد حاكمة
- لا انتقال قبل الختم.
- لا اعتماد على تقرير سابق وحده.
- لا تخمين.
- لا تعديل Source من دور الرقابة.
- أي High-risk action أو فجوة سلطة حاكمة = HOLD/ESCALATE.
- التقارير تبقى في مجلد الفريق، ويحدث سجل التسليم فقط.
