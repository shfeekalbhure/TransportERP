# Stop / Hold / Escalation Rules

يوقف الانتقال ويرفع مانعًا إذا ظهر: فقدان Authoritative line، دليل P0 غير محسوم، خطر فقدان بيانات/عزل/محاسبة، طلب حذف/دمج/نشر/تغيير مدمر، أو تعارض لا يمكن حسمه دون سلطة المالك.

الاستثناء التشغيلي المنضبط: لا يمنع اختلاف P0 بين تقارير مستقلة أو غياب Authoritative line فريق TEAM-D من تنفيذ المصالحة القرائية المخصصة له بعد تحقق أختام A/B/C1. يمنع ذلك إصدار حكم CURRENT نهائي أو عبور بوابة الجاهزية، ويصعد للمالك فقط عند ثبوت قرار يحتاج سلطته أو فعل عالي الخطورة.

حالات: `CONTINUE`, `HOLD`, `OWNER DECISION REQUIRED`, `ACCESS BLOCKED`, `UNKNOWN`.
