# مصفوفة الملكية والتسليم بين فرق كراسة الشاشات

**التاريخ:** 2026-08-28  
**الحالة:** حاكمة لتنظيم التحليل والمسودات — لا تمنح اعتمادًا وظيفيًا أو برمجيًا.

## الجذر الحاكم
`WORKSPACE_ROOT = CONTROL_TOWER/02_GROUP-02_EXPANSION/مساحة_عمل_فرق_كراسة_الشاشات_2026-08-28`

## قاعدة DRAFT MODE
فرق Wave A `01/02/04/05/07` يجوز لها العمل فقط وفق:
`00_فريق_تهيئة_مساحة_العمل/08_سياسة_DRAFT_MODE_ONLY_وضبط_العمل_المتوازي.md`

المسودة لا تساوي Handoff ولا تفتح بوابة.

## قاعدة السلطة
- **المالك:** صاحب الاعتماد الوظيفي النهائي وأي استثناء من البوابات.
- **الفريق 00:** تنظيم المساحة والمسارات والقوالب وسجل التسليم والمراجع فقط.
- **الفريق 08:** مراجعة ومصالحة مستقلة بعد اكتمال البوابات؛ لا يصنع بديلًا عن تقرير مفقود.

## ملكية التسعير والتعرفة
- 05 = المالك التحليلي للتعرفة/السعر/عرض السعر/العمولات/تكلفة الناقل/التحصيل.
- 04 = مدخلات التشغيل: المسافة والخط والمركبة والسعة والوزن/الحجم والخدمة والتوقف والانتظار وقيود الثقيل والجمارك التشغيلية.
- 05 لا يصبح `FINAL FOR HANDOFF` قبل أن يستهلك تقرير 04 `FINAL FOR HANDOFF` ويثبت SHA في تقريره.

## قرارات الحوكمة الحديثة الملزمة بالقراءة
- 05 يقرأ R-011 `ACC-001` قبل FINAL.
- 07 يقرأ R-012 `OFFLINE-001` وR-013 `CLIENT-001` قبل FINAL.
- 04 يقرأ R-012 عند تحليل Offline للعمليات.
- 03/06/08 تستخدم R-011..R-013 للمصالحة وعدم بناء مسودة على قرار أقدم.

## موجات العمل
### Wave A — DRAFT متوازي
`01 + 02 + 04 + 05 + 07`

يسمح بالمسودات فقط قبل PASS. عند فتح Handoff الرسمي:
- 01/02/04/07 يمكنها إنهاء FINAL بعد استيفاء مراجعها.
- 05 ينفذ جولة مطابقة إلزامية بعد 04 FINAL ثم ينهي FINAL.

### Wave B
`03` — يبقى WAITING حتى كل Final Handoffs لـ01/02/04/05/07 مسجلة `DELIVERED`.

### Wave C
`06` — يبقى WAITING حتى 03 و03-P Final/Delivered.

### Wave D
`08` — يبقى WAITING حتى جميع التقارير المطلوبة Final/Delivered.

## استثناء 08 — صيغة موحدة
أي استثناء مالك لا يكون صالحًا إلا إذا احتوى:
- `MISSING_INPUT`
- `EXCEPTION_REASON`
- `IMPACT_SCOPE`
- `ALLOWED_JUDGMENT`
- `PROHIBITED_JUDGMENTS`
- `DESIGN_GATE_EFFECT`
- `EXPIRY/BOUNDARY`

غياب أي حقل = `INVALID FOR TEAM-08 GATE`.

إذا كان الاستثناء لمراجعة جزئية ولم يسمح صراحة بفتح التصميم، فالحد الأعلى للحكم:
`PARTIAL RECONCILIATION UNDER OWNER EXCEPTION — INCOMPLETE INPUT SET — NO DESIGN GATE`.

## قاعدة الخلاف
1. لا يعدل فريق تقرير فريق آخر.
2. يسجل كل فريق رأيه ودليله.
3. يرفع التعارض إلى 08 عند فتحه.
4. القرار الوظيفي غير المحسوم يرفع للمالك.
