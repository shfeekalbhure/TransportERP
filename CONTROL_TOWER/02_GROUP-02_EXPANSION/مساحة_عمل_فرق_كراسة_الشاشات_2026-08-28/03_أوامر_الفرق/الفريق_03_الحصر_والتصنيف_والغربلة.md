# أمر الفريق 03 — فريق الحصر والتصنيف والغربلة

## المهمة
ابدأ بمسح شامل لكل الشاشات والوظائف المرشحة في نطاق المرحلة الأولى، ثم صنفها وغربلها دون فقد المتطلبات.

## المطلوب
1. قائمة خام قبل الدمج.
2. تصنيف كل عنصر: شاشة، تبويب، حاوية، نافذة إجراء، تقرير، طباعة، لوحة متابعة، مكوّن مشترك، أو غيره.
3. تصنيف بحسب الباب: تهيئة، إعدادات، بيانات رئيسية، تشغيل، تخطيط وإسناد، اعتماد ورقابة، عهدة، استلام وتسليم، تحصيل وتسويات، استعلام وتتبع، تقارير، طباعة، جوال، أمان وصلاحيات، وغيرها عند ثبوت الحاجة.
4. مصفوفة تشابه بين الركاب والبوالص والشحن والتوصيل والنقل الخفيف والمتوسط والثقيل.
5. تحديد المشترك والمتكرر وما يمكن دمجه وما يجب إبقاؤه مستقلًا.
6. عدد العناصر قبل الغربلة وبعدها مع سبب كل دمج أو فصل.

## الممنوع
- يمنع حذف متطلب لمجرد أنه مشابه؛ يجب نقل معناه إلى الشاشة المشتركة إذا دُمج.
- يمنع إنشاء شاشة مستقلة لكل إجراء صغير.
- لا تعديل للكراسة الرئيسية.
