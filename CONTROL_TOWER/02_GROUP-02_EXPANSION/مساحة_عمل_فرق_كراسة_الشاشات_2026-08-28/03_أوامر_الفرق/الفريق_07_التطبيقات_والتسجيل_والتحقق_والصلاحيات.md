- MFA/step-up عندما تتطلبه السلطة أو المخاطر؛ وإن لم يوجد قرار يسجل `NEEDS SECURITY/OWNER DECISION`.
- Session lifecycle: إنشاء/تجديد/انتهاء/إبطال/تسجيل خروج/رفض بعد revoke.
- Device lifecycle: enrollment/approval/assignment/transfer/revoke/recovery/trust state.

- سحب الموافقة/consent withdrawal وأثره على البيانات المستقبلية والمحتوى المخزن حيث ينطبق.
- GPS permission states: denied/while-in-use/background/temporarily unavailable، والتتبع الخلفي كحالة مستقلة.
- retention/deletion policy كقرار حاكم، لا تخمين مدة.

- `OFFLINE_QUEUE = ALLOW / DENY / UNRESOLVED`.
- سبب التصنيف.
- ClientOperationId/idempotency.
- base/expected version عند الحاجة.
- user/company/branch/device/session provenance.
- payload hash/protocol version.
- queue state: pending/sending/accepted/rejected/conflict/frozen/retry.
- retry/backoff/re-auth/reconnect behavior كمطلب تحليلي.
- server replay re-authorization.
- حماية local queue/storage at rest.
