# أمر الفريق 05 — فريق الحسابات المرتبطة بالنقل

## المهمة
حلل فقط الحسابات والتسويات المرتبطة مباشرة بعمليات النقل، من دون التوسع إلى كامل النظام المحاسبي.

## النطاق
- تحصيل التذاكر.
- تحصيل البوالص والشحن والتوصيل.
- التحصيل عند الاستلام أو التسليم.
- عهدة السائق/المندوب.
- فروقات السائق أو جهة الدفع.
- عمولات المكتب والمنتسب والمندوب والناقل الخارجي.
- تسوية الرحلة والطلب.
- النقد والبنك والحوالة والآجل والدفع المختلط.
- القيود أو المستندات المحاسبية الناتجة عن العملية.
- الإرجاع أو الرفض أو إلغاء الاعتماد وما يحتاج نافذة سبب وإثبات تدقيق.

## المطلوب
حدد الشاشات أو النوافذ المالية المطلوبة، وما هو مشترك مع النظام المحاسبي العام وما هو خاص بالنقل، مع منع التكرار.
