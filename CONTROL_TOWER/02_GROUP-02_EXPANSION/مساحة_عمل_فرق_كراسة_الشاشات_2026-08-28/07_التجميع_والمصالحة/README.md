# التجميع والمصالحة

لا يُستخدم هذا المجلد إلا بعد وصول تقارير الفرق والمراجعة المستقلة.

المطلوب لاحقًا:
- تجميع النتائج دون طمس مصدرها.
- حل التكرارات والتعارضات المثبتة.
- إعداد قائمة الشاشات المقترحة بعد الغربلة.
- إعداد بطاقات الشاشة المقترحة.
- إبراز النقاط التي تحتاج قرار المالك.
- إعداد نسخة مقترحة للكراسة للعرض على المالك.

لا تصبح النسخة المجمعة معتمدة تلقائيًا؛ اعتماد المالك مطلوب قبل فتح مرحلة التصميم البصري.
