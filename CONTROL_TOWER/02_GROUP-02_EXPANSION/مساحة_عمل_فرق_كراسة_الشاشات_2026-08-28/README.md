# مساحة عمل فرق كراسة الشاشات — 2026-08-28

هذه المساحة مخصصة لإعداد كراسة حصر وتحليل شاشات **النقل والحسابات المرتبطة بالنقل**.

## البداية الإلزامية

قبل إطلاق أي فريق تحليلي، تُراجع ملفات:

`00_فريق_تهيئة_مساحة_العمل/`

هذا الفريق مسؤول عن تنظيم المساحة وصياغة تعريفات وتكليفات الفرق وقوالب التسليم فقط، ولا ينفذ تحليلًا وظيفيًا ولا تصميمًا ولا برمجة.

## الترتيب

- `00_فريق_تهيئة_مساحة_العمل/` — تعريف الفريق 00، معيار صياغة التكليفات، قوالب إنشاء الفرق وأوامر الإطلاق، وسجل الجاهزية.
- `00_اقرأ_أولاً/` — قرار المالك والنطاق والقواعد الحاكمة.
- `01_الكراسة_الرئيسية/` — الكراسة المرجعية التي تعمل الفرق على أساسها ولا تعدلها مباشرة.
- `02_المراجع/` — فهرس المراجع الداخلية والخارجية المطلوب فحصها.
- `03_أوامر_الفرق/` — أمر مستقل ومختصر لكل فريق.
- `04_تقارير_الفرق/` — وجهة تقارير الفرق.
- `05_المراجعة_المستقلة/` — مراجعة ومصالحة مستقلة بعد وصول مخرجات الفرق.
- `06_التصميم_البصري_لاحقاً/` — لا يبدأ إلا بعد اعتماد المالك لنتائج التحليل.
- `07_التجميع_والمصالحة/` — تجميع النسخة المقترحة النهائية للعرض على المالك.

## قاعدة العمل

كل فريق لاحق يجب أن يكون له قبل الإطلاق:

1. تعريف واضح للفريق وصفته.
2. أعضاء بالصفات الوظيفية.
3. هدف ونطاق محددان.
4. مراجع إلزامية بالترتيب.
5. ممنوعات وصلاحيات.
6. مخرج محدد واسم ملف ومسار تسليم.
7. قاعدة لرفع الغموض والتعارض إلى المالك بدل التخمين.

كل فريق يقرأ `00_اقرأ_أولاً` ثم الكراسة الرئيسية ثم أمره الخاص. الفريق لا يغير الأصل، بل يسلّم تقريرًا موثقًا في مساره. أي قرار غير محسوم يرفع للمالك بدل افتراضه.

## قاعدة الإطلاق من المحادثة

تكون كل فرقة في **محادثة عمل مستقلة**. يستخدم أمر إطلاق مختصر يشير إلى ملف تكليفها الكامل داخل مساحة العمل؛ ولا يعاد نسخ الكراسة والتفاصيل الطويلة في كل محادثة.

## حدود المرحلة الحالية

- لا Source Code.
- لا Tests.
- لا Database أو Migrations.
- لا حذف أو نقل أو إعادة تسمية ملفات المشروع دون أمر المالك.
- لا تصميم بصري قبل فتح مرحلته.
- لا تنفيذ برمجي قبل اعتماد المالك الصريح.
