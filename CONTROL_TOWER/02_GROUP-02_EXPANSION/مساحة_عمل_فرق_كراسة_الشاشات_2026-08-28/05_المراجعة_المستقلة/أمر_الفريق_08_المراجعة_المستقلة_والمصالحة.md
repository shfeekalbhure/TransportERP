# أمر الفريق 08 — فريق المراجعة المستقلة والمصالحة

## 1. الهوية والحالة
**الصفة:** فريق مراجعة مستقل عن فرق 01–07 وعن فريق 00.  
**الموجة:** D.  
**الحالة:** `WAITING FOR ALL FINAL HANDOFFS — DO NOT START RECONCILIATION`.

## 2. بوابة البدء الصارمة
لا تبدأ حتى يثبت سجل التسليم أن جميع المدخلات التالية `DELIVERED` وفق `FINAL FOR HANDOFF` وبها blob/commit SHA:
- تقرير 01 النهائي.
- تقرير 02 النهائي.
- تقرير 03 النهائي.
- سجل 03-P النهائي.
- تقرير 04 النهائي.
- تقرير 05 النهائي، ويجب أن يثبت استهلاك SHA تقرير 04 النهائي.
- تقرير 06 النهائي.
- تقرير 07 النهائي.

أي ملف `*_DRAFT.md` أو حالة `DRAFT` لا يُعد مدخلًا ولا يفتح البوابة.

## 3. استثناء المالك
أي استثناء لا يكون صالحًا إلا إذا احتوى جميع الحقول:
- `MISSING_INPUT`
- `EXCEPTION_REASON`
- `IMPACT_SCOPE`
- `ALLOWED_JUDGMENT`
- `PROHIBITED_JUDGMENTS`
- `DESIGN_GATE_EFFECT`
- `EXPIRY/BOUNDARY`

غياب أي حقل = `INVALID FOR TEAM-08 GATE`.

إذا كان الاستثناء جزئيًا ولم يسمح صراحة بالتصميم، فالحد الأعلى للحكم:
`PARTIAL RECONCILIATION UNDER OWNER EXCEPTION — INCOMPLETE INPUT SET — NO DESIGN GATE`.

يحظر توسيع الاستثناء أو استنتاج حكم غير مكتوب.

- طابق المتطلبات ← التشغيل/المالي/القنوات ← Population/Disposition ← بطاقات الشاشات.
- استخدم `A11-LIVE` فقط وفق سجل الهوية؛ النسخة الأرشيفية ليست بديلًا.

- تحقق من عدم إنشاء IDs موازية لـA11؛ Local Candidate فقط عند `NO A11 MATCH` موثق.
- صالِح المطالبات/التلف/النقص/الفقد/رفض التسليم/الإرجاع بين 04/05/07.
